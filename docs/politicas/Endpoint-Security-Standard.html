1. Purpose

This standard defines the minimum security configuration of every company computer, to protect company systems and customer data from malware, unauthorized access and device loss. It supports the Information Security Policy.

2. Minimum requirements

ControlRequirement
Antivirus / anti-malwareAnti-malware software is installed and active on every company computer: Microsoft Defender Antivirus (built into Windows), with real-time protection enabled and automatic signature updates. Computers are not used for company work if protection is disabled.
Operating system updatesWindows Update is set to install updates automatically. Critical security updates are installed as soon as they are available.
Screen lockComputers lock automatically after a period of inactivity and require the user's credentials to unlock.
PasswordsEach person uses an individual account with a strong, unique password. Passwords are never shared. A password manager is recommended.
Disk encryptionThe disks of company computers are encrypted (Windows BitLocker), so data remains protected if a device is lost or stolen.
Multi-factor authentication (MFA)MFA is enabled on the company's Microsoft 365 accounts (including e-mail), on the source-code repository (GitHub) and on the other administrative services used to operate the platform.
E-mail protectionThe company's e-mail is provided by Microsoft 365 (Exchange Online), which filters malware and phishing messages before delivery.

3. Safe use

  • Install software only from trusted sources. Do not open unexpected attachments or links; report suspicious messages to suporte@vgon.com.br.
  • Do not store customer data on removable media or personal devices.
  • Restricted information (passwords, tokens, keys, certificates, personal data) must never be sent by chat or e-mail in clear text or stored in source code.
  • Keep documents with restricted or confidential data out of sight when leaving the workstation (clean-desk rule).

4. Lost or stolen devices and departures

  • The loss or theft of a computer must be reported immediately. Access of that device and the user to company accounts is revoked, and passwords and tokens that may have been exposed are changed.
  • When a person leaves the company, their accounts are disabled on the same day and the computer is returned and cleaned.

5. Verification and exceptions

The Information Security Officer verifies at least twice a year that every computer meets the requirements above (antivirus active, updates current, screen lock set, disk encrypted, MFA enabled). Exceptions must be requested in writing, approved by management and have an end date. A computer that does not meet the requirements must be fixed before it is used with customer data.
